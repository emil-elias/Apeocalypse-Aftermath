# Apeocalypse: Aftermath
### a Media Engineering Projektschen

Das Spiel Apeocalypse: Aftermath wurde, im Rahmen der Veranstaltung Media Engineering WS 22/23 an der Universität Bremen, 
in Eigenarbeit von folgenden Personen entwickelt:

Artworks:
- Ruven Bellmann
- Nikolaos Dhimitri

Leveldesign, GUI-Entwicklung:
- Dario Aberle
- Leonard Kiefner

Programmierung:
- Bennet Tast
- Emil Wilde

Musik:
- Maxim Triller

Verwendete Ressourcen von Dritt-Personen verletzen kein Lizenzrecht und/oder Copyright.
Referenzen sind in der lizenzen.txt zu finden.
