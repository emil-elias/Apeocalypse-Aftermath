Beim Öffnen des Unreal-Projektes kann es passieren, dass ein Dialog darauf hinweist, dass ein Rebuild des Game-Modules erforderlich ist. In der Regel sollte sich der Rebuild einfach über diesen Dialog durchführen lassen (sofern Visual Studio mit den enstprechenden Erweiterungen oder ein anderer verknüpfter Compiler vorhanden ist). 
Falls nicht, kann es nötig sein das Projekt über Visual Studio oder auf anderem Wege neu zu kompilieren. 
Falls es diesbezüglich Probleme geben sollte, bitte melden.
